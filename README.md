# Predicting Flight Delays

## Project Overview

This project uses machine learning classification methods to predict U.S. flight delays based on information available before departure, including airline carrier, flight route, scheduled departure time, and date-related variables.

The objective was to compare different classification models and evaluate their ability to predict delayed flights while accounting for class imbalance in the dataset.

## Methods

The analysis included:

- **Data preprocessing:** Prepared and organized flight data for statistical modeling.
- **Feature selection:** Used airline, route, scheduling, and date-related variables available before departure.
- **Classification modeling:** Developed and compared logistic regression, linear discriminant analysis (LDA), random forest, and classification and regression tree (CART) models.
- **Model evaluation:** Compared predictive performance using classification accuracy and ROC/AUC analysis.
- **Class imbalance:** Evaluated model performance while considering the unequal distribution of delayed and non-delayed flights.

## Models Used

- Logistic Regression
- Linear Discriminant Analysis (LDA)
- Random Forest
- Classification and Regression Tree (CART)

## Results

Logistic regression demonstrated the strongest overall performance among the models evaluated, achieving approximately 85% classification accuracy compared with a baseline of approximately 82%.

The results highlighted the limitations of predicting flight delays using only pre-departure information, particularly when delayed flights are underrepresented in the dataset.
