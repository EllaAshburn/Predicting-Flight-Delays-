# Predicting Flight Delays

Built and compared machine learning classification models to predict U.S. flight delays using pre-departure airline, route, and scheduling data. This project highlights skills in data preprocessing, classification modeling, model comparison, and performance evaluation under class imbalance.

## Methods Used
- Logistic Regression
- Linear Discriminant Analysis (LDA)
- Random Forest
- Decision Tree (CART)

## Project Focus
The goal was to predict whether a flight would arrive late using only information available before departure, such as airline carrier, origin and destination airports, scheduled departure time, and date-related variables.

## Key Takeaway
Logistic regression performed best overall, though results showed that pre-departure variables alone offer only modest predictive power, especially when delayed flights are underrepresented in the data.
